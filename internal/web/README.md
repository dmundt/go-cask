# web — the embedded viewer server

Package `web` implements the embedded technical viewer behind `/viewer/*`: the
login page and startup-token deep link, session cookies and role authorization,
CSRF-protected mutations, the object browser over the store, and the htmx
fragments it swaps. `cmd/cask web` is its only caller and only wires it — it
does not reimplement any part of it.

## Composition points

`web.Config` is where a host supplies everything the viewer cannot know on its
own:

- `Hasher` / `HashAlgorithm` — digest parsing, validation, and verification.
- `StartupToken` — the admin credential; generated by `cmd/cask web` or taken
  from `-token-file`/`CASK_VIEWER_TOKEN`, never logged.
- `RoleTokens` — additional `role=token` logins.
- `TrustedProxies` — the peers whose forwarded client address the login
  throttle may believe; empty trusts none.
- `References` (`ReferenceIndex`) — host-supplied inbound/outbound edges. Nil
  leaves references unavailable.
- `Reachability` (`ReachabilityIndex`) — host-computed root reachability. Nil
  leaves the orphan state unavailable.

Those last two are the whole reason the viewer can show reference states at
all: without them the `References` column is hidden and every `reach` query
answers `400`. `cmd/cask web` supplies both from the deterministic preview graph
`cask seed-preview` writes; an embedding host supplies its own.

## Boundaries

- The viewer inspects; it does not destroy. There is no delete or GC route, and
  no typed reference resolution — it reads bytes, envelope types, sizes, and
  physical metadata only.
- One stylesheet (`viewer.css`) and one script (vendored htmx). No inline
  styles beyond what htmx injects, no hand-written JavaScript, no build step.
- Templates are server-rendered with `html/template`; every fragment reuses the
  partial a full page composes, so there is one source of truth per component.

The user-facing explanation of the viewer — what it is, how to start it, what
an operator sees, and what the reference states mean — is the
[viewer page](https://go-cask.dev/viewer/) on the documentation site.

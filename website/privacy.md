## Hosting on GitHub Pages

This website is provided as a static website through GitHub Pages. GitHub
provides this service and, depending on the processing activity, identifies
GitHub, Inc., 88 Colin P Kelly Jr Street, San Francisco, CA 94107, USA, or
GitHub B.V. as the controller. When this website is accessed, GitHub processes
the device's IP address and technical connection data in particular. GitHub
states that it logs and stores the IP addresses of visitors to GitHub Pages
websites for security purposes, regardless of whether they are signed in.

This processing is necessary to provide the website securely and reliably. Its
legal basis is Article 6(1)(f) GDPR. The legitimate interest is the secure and
reliable operation of this open-source project documentation.

GitHub also processes personal data in the United States and other countries
outside the European Economic Area. GitHub states that it generally relies on
the European Commission's Standard Contractual Clauses for transfers to
countries without an adequacy decision. GitHub, Inc. is also certified under
the EU-US Data Privacy Framework. Further details, including information about
the safeguards and how to obtain them, are available in
[GitHub's General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
The Standard Contractual Clauses are published in
[Commission Implementing Decision (EU) 2021/914](https://eur-lex.europa.eu/eli/dec_impl/2021/914/oj).

Links to external websites, particularly GitHub and pkg.go.dev, transfer data

## Retention

The operator of this website does not receive separate server logs or create
visitor profiles. GitHub does not publish a fixed retention period for IP log
data generated by GitHub Pages. According to GitHub, retention depends on the
purpose of the processing and applicable contractual and legal retention
obligations.

## Right to object

Where processing is based on Article 6(1)(f) GDPR, you may object to that
processing at any time on grounds relating to your particular situation. The
personal data concerned will then no longer be processed unless there are
compelling legitimate grounds for the processing that override your interests,
rights, and freedoms, or the processing is necessary for the establishment,
exercise, or defence of legal claims.

## Data subject rights

Subject to the GDPR's requirements, data subjects have rights of access,
rectification, erasure, restriction of processing, data portability, and
objection. Data subjects also have the right to lodge a complaint with a data
protection supervisory authority. Requests may be sent to the email address
provided in the [legal notice](impressum.md).

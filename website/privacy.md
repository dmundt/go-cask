# Privacy

## Controller

The controller responsible for this website is Daniel Mundt. The address and
contact details are provided in the [legal notice](impressum.md).

## Hosting on GitHub Pages

This website is provided as a static website through GitHub Pages. GitHub
provides this service. The website operator decides to use GitHub Pages to make
this open-source project documentation available and is the controller for
that decision. The legal basis is Article 6(1)(f) GDPR. The legitimate interest
is the secure and reliable public operation of the documentation.

GitHub states that, depending on the processing activity, GitHub, Inc.,
88 Colin P Kelly Jr Street, San Francisco, CA 94107, USA, or GitHub B.V. acts
as an independent controller for its processing. GitHub determines the
purposes and legal bases of that processing as described in
[GitHub's General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Data categories and purposes

When this website is accessed, the visitor's browser automatically transmits
connection data to GitHub so that GitHub Pages can deliver the requested
content. GitHub expressly states that it logs and stores visitors' IP addresses
for security purposes, regardless of whether they are signed in.

According to GitHub's General Privacy Statement, the data processed may also
include device, browser, operating-system, request, and session details; the
date and time of requests; requested pages; the referring website; links
clicked; and an approximate region inferred from the IP address. GitHub uses
such data to provide the service, maintain security, prevent abuse, and operate
and improve its services.

## Recipients

Recipients of connection data may include GitHub, Inc., GitHub B.V., their
affiliates, and service providers or subprocessors used for hosting, content
delivery, infrastructure, and security. GitHub publishes its current
[subprocessor list](https://docs.github.com/en/site-policy/privacy-policies/github-subprocessors).
GitHub may also disclose data to public authorities where legally required.

## Requirement to provide data

Providing connection data is not a statutory or contractual requirement. It is
technically necessary to retrieve this website: without transmitting an IP
address and request data to GitHub Pages, the requested content cannot be
delivered.

## International data transfers

GitHub also processes personal data in the United States and other countries
outside the European Economic Area. GitHub states that it generally relies on
the European Commission's Standard Contractual Clauses for transfers to
countries without an adequacy decision. GitHub, Inc. is also certified under
the EU-US Data Privacy Framework. Further details, including information about
the safeguards and how to obtain them, are available in
[GitHub's General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
The Standard Contractual Clauses are published in
[Commission Implementing Decision (EU) 2021/914](https://eur-lex.europa.eu/eli/dec_impl/2021/914/oj).

## Cookies and browser storage

This website does not use cookies or store information in local or session
browser storage.

## External links

Links to external websites, particularly GitHub and pkg.go.dev, transfer data
to the respective provider only when clicked. The provider's privacy notice
applies to its processing of that data.

## Retention

The operator of this website does not receive separate server logs or create
visitor profiles. GitHub does not publish a fixed retention period for IP log
data generated by GitHub Pages. According to GitHub, retention depends on the
purpose of the processing and applicable contractual and legal retention
obligations.

## Automated decision-making

The website operator does not use automated decision-making or profiling.

## Right to object

Where processing is based on Article 6(1)(f) GDPR, you may object to that
processing at any time on grounds relating to your particular situation. The
personal data concerned will then no longer be processed unless there are
compelling legitimate grounds for the processing that override your interests,
rights, and freedoms, or the processing is necessary for the establishment,
exercise, or defence of legal claims.

## Data subject rights

Subject to the GDPR's requirements, data subjects have rights of access,
rectification, erasure, restriction of processing, data portability, and
objection. Data subjects also have the right to lodge a complaint with a data
protection supervisory authority. Requests concerning processing controlled by
the website operator may be sent to the email address provided in the
[legal notice](impressum.md). Requests concerning processing controlled by
GitHub should be directed to GitHub using the contact details in
[GitHub's General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
